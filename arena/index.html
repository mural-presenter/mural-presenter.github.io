∞-Brush: Restructuring the Results

11 slides
Qwen3.8-27B · Trained

Five editing turns refine a research talk. The final request separates datasets, baselines, global structure, and local detail into distinct slides.

Turn 5 request

Separate datasets, baselines, global results, and local results into four distinct slides.

What changedThe experimental section grows from three pages to four. The full deck stays at 11 pages; the earlier limitations page is no longer present.

Read the original request

Revise the ‘Experimental Setup’ and ‘Results’ sections to explicitly structure them into separate slides that match the granularity of datasets/conditioning, baselines/metrics, global-structure results, and local-detail results. Make sure each experimental slide clearly states which dataset and resolution is being discussed, what conditioning signal is used, and which baselines are compared, then summarize the quantitative outcome in a single takeaway bullet per slide rather than mixing global and local metrics together. Keep the level of technical detail similar to the rest of the deck but streamline phrasing to be more concise and presentation-ready (short bullets, no long sentences). Do not add new metrics or datasets beyond those already mentioned; focus only on reorganizing and clarifying what is there.

SGD: Proof vs. Empirical Evidence

10 slides
Qwen3.8-27B · Trained

Iterative edits clarify the golden path hypothesis. The final request distinguishes a convex theorem from empirical findings in non-convex networks.

Turn 5 request

Remove the misleading theorem label from the non-convex slide and explicitly identify experimental evidence.

What changedThe heading adds “Empirical Evidence”; the opening changes from “Main result — Theorem 2.1” to “Observed, not proven”.

Read the original request

Revise the slide titled “The Non-Convex Case: SGD Noise Is Still Insignificant” so that it clearly distinguishes the formal convex result (Theorem 2.1) from the separate non-convex, empirical findings: make the heading emphasize that the non-convex case is supported only by experiments, remove the misleading phrase “Main result — Theorem 2.1 (convex case)” from that slide, and instead summarize that in realistic non-convex neural networks the golden path hypothesis is observed empirically (on architectures like ResNet-18, ConvNeXt-T, and GPT-2-small) without claiming a theorem. Keep the existing bullet structure but adjust wording to avoid suggesting there is a formal non-convex theorem, and explicitly state that the non-convex results are evidence rather than a proof.

About this selection

Different tasks. Different measures.

ThreadEval focuses on long-horizon authoring; PresentBench and SlidesGen-Bench cover complete generation tasks. DeckBench starts with an existing presentation and follows five editing turns. Each case identifies its model and provides the original evaluated PDF or a compilation of evaluated renders.

These examples are selected for readability and task behavior, not as benchmark averages. SlidesGen-Bench case scores report content accuracy. DeckBench’s ΔDTW and ΔTransSim measure changes in semantic alignment, not visual aesthetics. See the leaderboard for full experiment results.
